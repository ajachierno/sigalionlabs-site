# sigalionlabs.com

The Sigalion Labs website: a single static page for Mystiko.

Plain HTML, CSS and JavaScript. No build step, no frameworks, no external fonts or scripts.

- `index.html`: the six screens
- `styles.css`: layout and effects
- `app.js`: the sliding deck, the resolving text and the background

To preview, serve the folder with any static server, for example `python -m http.server`.

Prices on the levels screen are placeholders until the Google Play products are created.
